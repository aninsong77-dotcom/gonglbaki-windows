# 사례서랍 파일 자동 정리 — 계획 (2026-08-06)

## 목표

사례서랍에 파일을 첨부하면 **실제 파일도 사례 폴더 안으로 이동**해서, 사용자가 따로 파일 정리를
하지 않아도 되게 한다. (지금은 경로만 기록해서, 사용자가 파일을 옮기면 연결이 끊긴다.)

## 확정된 설계 (사용자 결정, 2026-08-06)

### 폴더 구조

```
사례서랍 루트/
└─ 홍길동/                     ← 내담자 폴더 (현재도 자동 생성됨)
   ├─ _사례정보.json           ← 정리 정보 (현재도 저장됨)
   ├─ 01회기/                  ← 음성 · 축어록(docx) · 축어록 세션(json) · 분석
   ├─ 02회기/                  ← 두 자리 고정(10회기 넘어가도 순서대로 정렬되게)
   ├─ 슈퍼비전/
   ├─ 심리검사/                ← 심리검사 결과 + 심리검사 슈퍼비전 보고서
   └─ 기타/                    ← 가계도 포함
```

- **가계도 → `기타/`** (내담자당 하나지만 별도 폴더 안 만들고 기타에)
- **축어록은 docx + `_세션.json` 을 짝으로 관리** (같은 회기 폴더에)

### 동작 방식

- **복사가 아니라 이동** — 원래 폴더에서는 사라지고 사례 폴더로 감
- **파일 이름은 원래 이름 그대로** — 폴더가 이미 분류 역할을 하고, 보고서·검사지 이름에 담긴
  정보(작성자·검사 종류 등)를 보존하기 위함. 같은 이름이 이미 있으면 뒤에 `(2)`, `(3)` 붙임

## 안전 장치 (파일이 사라지지 않게)

파일 이동은 실패하면 상담 자료가 유실될 수 있으므로 아래를 지킨다.

1. **이동은 "복사 → 확인 → 원본 삭제" 순서로.**
   `rename` 한 방으로 처리하면 다른 드라이브(예: C→D, USB) 간에는 실패한다. 복사가 끝나고
   **크기 비교로 온전히 복사됐는지 확인한 뒤에만** 원본을 지운다. 확인이 안 되면 원본을 남긴다.
2. **실패해도 첨부 자체는 살린다.** 이동에 실패하면(파일이 열려 있어 잠김, 권한 없음 등)
   원래 경로로 연결만 해두고 "파일 정리는 실패했지만 첨부는 됐다"고 알린다.
3. **이미 사례 폴더 안에 있는 파일은 건드리지 않는다.** (재첨부·중복 이동 방지)
4. **처음 한 번 안내.** "첨부한 파일은 사례서랍 폴더로 이동합니다(원래 위치에서 사라짐)"를
   최초 1회 안내하고 동의를 받는다. 파일이 없어졌다고 놀라지 않게.

윈도우·맥 양쪽에 동일 적용.

## 기존 첨부분 처리 — 마이그레이션 기능 불필요 (2026-08-06 결정)

현재 사례서랍은 **파일 경로만 json 에 적어두는 방식**이라, 등록된 사례를 지워도 실제 파일은
그대로 남는다. 지금 등록돼 있는 것은 테스트용이므로 **사용자가 사례를 전부 지우고 새로 첨부**하기로
했다. 따라서 "기존 파일 일괄 이사" 기능은 만들지 않는다(작업량·사고 위험 둘 다 감소).

## 구현 완료 (2026-08-06) — 윈도우만

| 파일 | 내용 |
|---|---|
| `electron-main.cjs` | `case-move-file` IPC — 복사 → 크기 검증 → 원본 삭제. 중복명 `(2)` 처리. 이미 목적지에 있으면 그대로 둠 |
| `preload.cjs` | `moveFile` 노출 |
| `CaseDrawer.tsx` | `placeFile()` 헬퍼 + 첨부 지점 전부 연결(가계도·심리검사·슈퍼비전·회차별 음성/축어록/분석, 새 사례 만들기 화면 포함) |

- **축어록 짝 json 자동 동행**: 워드 축어록을 첨부하면 옆에 있던 `○○_세션.json` 을 찾아 같은 회기
  폴더로 함께 옮기고 `transcriptJson` 에 연결한다(이어서 편집 가능하도록).
- **새 사례 만들기 화면**의 첨부는 폴더명이 정해지기 전이므로, 사례 생성 직후에 옮긴다.
- **최초 1회 동의**: "파일이 이동됩니다" 안내에 [취소]하면 `gb_case_move_notice=off` 로 기록되어
  **예전처럼 경로만 연결**한다(원치 않는 사용자를 위한 탈출구).
- 기타자료(특정 내담자에 속하지 않는 자료) 는 대상 아님 — 그대로 경로 연결 방식 유지.

### 함께 고친 것 — 회차 관리 (2026-08-06)

파일 정리 테스트 중 사용자가 발견: "자료를 지웠는데 상담 회차가 그대로 남아 있다".

- **[확인] 회차 삭제 기능이 아예 없었다.** "회차 추가"만 있고 지우는 방법이 화면에 없어서,
  실수로 추가한 회차를 되돌릴 수 없었다. → 각 회차에 **삭제(휴지통) 버튼 추가.**
  자료가 붙은 회차를 지울 땐 `첨부된 자료 N개의 연결이 함께 사라집니다`라고 알리고 확인받는다
  (파일 자체는 사례 폴더에 남는다).
- **[확인] `N회차` 표시는 "회차 칸 개수"였다** — 첨부를 지워도 칸이 남아 숫자가 그대로였다.
  → 자료가 실제로 붙은 회차 수를 함께 표시: 빈 칸이 있을 때만 `3회차 (자료 1)` 형태로 보여준다.

### 폴더 생성 시점

- **내담자 폴더**: 사례를 만들 때 즉시 생성(기존 동작)
- **하위 폴더(01회기·슈퍼비전·심리검사·기타)**: **해당 종류의 파일을 처음 첨부할 때** 생성.
  회차만 추가하고 파일을 안 넣으면 빈 폴더가 생기지 않는다.
